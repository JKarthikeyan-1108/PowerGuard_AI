# Manuals

PowerGuard features distinct portals tailored to specific user roles.

## 1. Admin Manual (`/admin`)
The Admin portal is the command center for the entire platform.
- **User Management**: Admins can approve, suspend, or delete users.
- **Grid Topology**: Admins manage Areas, Transformers, and register new Smart Meters.
- **System Health**: Access real-time server metrics (CPU, RAM) and audit logs.
- **Security**: Configure global platform settings and review critical security incidents.

## 2. Utility Officer Manual (`/officer`)
Designed for field workers and grid managers.
- **Incident Management**: View assigned alerts (e.g., suspected theft) and update their resolution status.
- **Meter Monitoring**: View live telemetry data for specific meters under their jurisdiction.
- **Reports**: Generate PDF/Excel reports for regional energy consumption and loss analysis.

## 3. Consumer Manual (`/consumer`)
A simplified, user-friendly interface for end-users.
- **Usage Dashboard**: View real-time energy consumption and historical trends.
- **Billing Predictions**: See AI-generated estimates for the upcoming electricity bill.
- **Alerts**: Receive notifications about unusual consumption spikes or grid outages.
- **Recommendations**: View AI-generated tips to improve energy efficiency.
